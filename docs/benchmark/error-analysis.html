Five signals worth following up on:

  1. List-completeness remains the dominant fixable mode (35 of 113). Conv-50 added one more (Q60 Calvin's artist-friend gifts: necklace identified, custom-octopus-guitar missed because line-150 phrasing is ambiguous between commission and gift). Across the dataset, list-completeness misses share a common shape: the missing item is recorded under a different surface form, in a temporally distant session, or under a different thematic emphasis than the surfaced items. Two complementary fixes: (a) cross-encoder reranking on answer-shape match for list questions, (b) multi-aspect indexing on memory nodes.
  2. Specificity / framing stays at 26 of 113 (no new conv-50 cases). Conv-50's only specificity-shaped miss was rescued (Q120 verbatim "broken to awesome" was captured by the agent in its 4th bullet but penalized for dilution).
  3. Retrieval-anchor mismatch surfaced as a new sub-mode (conv-50 Q72). The agent had Aerosmith correctly indexed (it answered Q3 "bands Dave likes" with both Aerosmith and The Fireworks) but did not retrieve it for Q72's temporal-anchor query "April 2023 music festival favorite." This is similar to the existing "Wrong evidence chosen" pattern but the failure was retrieval-side, not reasoning-side — the right node existed in the graph but the query embedding for "April 2023 favorite" did not surface it. Suggests query-side anchoring (date + event-type + role) could complement node-side indexing.
  4. Strict inference / over-cautious commitment stays at 11 (no new conv-50 cases). The pattern now spans conv-43 (ankle chain), conv-44 (plan evolution), conv-47 (multi-game / source-thin), conv-48 (multi-retreat).
  5. Multi-hop referent-aliasing — same root pattern as strict-inference; cross-session entity-bridging. No new conv-50 cases — conv-50 hit 100% rescored multi-hop, the fourth conversation to do so.
