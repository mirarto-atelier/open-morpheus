Hallucination rate: 5 / 1,977 = 0.25%.

Across the entire 1,977-question suite, Morpheus produced only 2 invented facts on non-adversarial questions (conv-41 Q21 "California family vacation", conv-42 Q67 "Fish — kept in a tank at home") and 3 wrong commits on adversarial speaker-swap questions (conv-43 Q195, conv-44 Q123, conv-47 Q162). Every other miss was a retrieval gap, specificity loss, or framing disagreement — cases where the agent's answer was traceable to source, not invented. For an LLM-driven memory system, a 0.25% fabrication rate over thousands of long-context retrievals is the property that makes the graph actually trustable as long-term memory.

Key Features

  • Three-branch graph — Semantic (facts), Episodic (events by date), Procedural (workflows)
  • Fly Swatter Search — FTS5 + vector hits with ranked neighborhood expansion
  • 3 MCP tools — morpheus_search, morpheus_get_node, morpheus_get_conversation
  • One fact per leaf — granular nodes for precise retrieval
  • Episodic ±14 day window — automatic temporal context on node exploration
  • Procedural subtree expansion — search auto-returns full procedure with steps and pitfalls
